# YantraFox — Free Online PDF, SEO, AI & Developer Tools Suite

> High-performance, browser-first collection of 86+ utilities for PDF manipulation, client-side image compression, developer formatting, SEO auditing, AI generation, and financial calculations. All processing runs 100% locally in browser memory (RAM) with zero cloud file storage.

## Privacy & Client-Side Architecture

Every file, image, document, and text snippet provided to YantraFox is processed directly inside the user's browser using WebAssembly (WASM), Web Workers, and HTML5 Canvas. No user data or uploaded files are ever sent to remote servers or stored in the cloud.
